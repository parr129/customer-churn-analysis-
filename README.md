# Customer Churn Analysis — PwC Virtual Internship

A Power BI dashboard project built as part of the **PwC Switzerland Virtual Internship** on Forage, focused on analyzing customer churn behavior in the telecom industry to drive retention strategies.

## Key Performance Indicators (KPIs)

| Metric | Value |
|--------|-------|
| Total Customers | 7,043 |
| Total Charges | $16.06M |
| Avg. Monthly Charges | $64.76 |
| Churn Rate | 26.54% |
| Retention Rate | 73.46% |

## Tools & Tech Stack

- **Power BI** — Interactive dashboard design and DAX measures
- **Microsoft Excel** — Data source (23 columns, 7,043 records)
- **DAX** — Calculated KPIs and churn metrics


## Key Insights

- **Contract Type is the #1 churn driver** — Month-to-month contracts show the highest churn rate; 2-year contracts have the highest retention.
- **Fiber optic internet** is the most popular service but also correlates with higher churn, suggesting pricing sensitivity.
- **Electronic check** is the most common payment method among churned customers, indicating a billing friction point.
- **Paperless billing** is preferred by the majority of customers, with churned customers skewing heavily toward it.
- **Demographics** — Dataset includes 3,402 partners, 2,110 dependents, and 1,142 senior citizens, revealing churn variation across segments.

## Recommendations

- **Proactive retention offers** — Target month-to-month customers approaching 12 months with upgrade incentives.
- **Contract migration campaigns** — Incentivize longer-term commitments via discounts on 1-year and 2-year plans.
- **Payment method optimization** — Promote auto-pay enrollment to reduce billing-related churn.
- **Segment-specific strategies** — Design tailored retention programs for senior citizens and single-person households.
- **Continuous monitoring** — Set up churn risk scoring in Power BI using DAX to flag at-risk customers monthly.
